# Shell Scripting Practice & Reference

A collection of Bash scripts and exercises covering Linux shell scripting fundamentals, control flow, functions, parameters, and utilities.

## Topics Covered

- **Variables & Scoping**: Parameter expansion, local vs global variables, CLI arguments (`var*.sh`, `scope.sh`, `myvar2.sh`).
- **Control Flow**: `for` and `while` loops, conditional testing (`for*.sh`, `while*.sh`, `test*.sh`).
- **Functions & Libraries**: Defining reusable functions, passing arguments, return codes, and sourcing shared libraries (`function*.sh`, `common.lib`, `return.sh`).
- **Algorithms & Utilities**: Calculation examples (e.g., `factorial.sh`), user input prompts, user management demos.

## Usage

Ensure scripts have execute permissions before running:

```bash
chmod +x <script_name>.sh
./<script_name>.sh
```
